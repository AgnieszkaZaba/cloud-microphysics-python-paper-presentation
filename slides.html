physical units in code with Pint



physical units with Pint (example: ideal gas density)

\[\rho = (p M) / (T R)\]

import pint
SI = pint.UnitRegistry()
SI.setup_matplotlib()

pressure = 1000 * SI.mbar
temperatures = numpy.linspace(250, 300) * SI.K
gas_const = scipy.constants.R * SI.J / SI.K / SI.mol
molar_mass = (0.78 * 2 * mendeleev.N.atomic_weight +
              0.22 * 2 * mendeleev.O.atomic_weight) * SI.g / SI.mol

density = (pressure * molar_mass) / (gas_const * temperatures)
plt.plot(temperatures, density)
  • changed names of variables
  • axis labels automatic

Pint: key takeaways

  • ⚖️ performs dimensional analysis (unit testing!)
  • ⚙️ automates plot axis labelling (and consistency checks)
  • 💱 handles SI prefixes and unit conversions
  • 🩺 helps in debugging (print(x) prints a value with unit)

injectable constants-catalogue idiom


💡 key (physics) principle: dimensionality of physical quantities originates from constants only!
 ❶ \(\leadsto\) instantiate a constants catalogue at topmost scope, pass to all physics-related functions
 ❷ \(\leadsto\) use unit-aware constants catalogue for unit testing
 ❸ \(\leadsto\) use plain-floats constants catalogue elsewhere


  • ✅ no trade-off in code readibility or performance
  • ✅ no trade-off in functionality (e.g., SI prefixes, unit conversions, …)
  • ✅ no trade-off in interoperability with numerical routines or JIT compilers
  • 💡 works with any language supporting JIT compilation (e.g., Julia) or templates (e.g., C++)
  • ➕ positive side-effect: enforces separation of concerns
